# PinGo

PinGo는 외국인 관광객을 위한 지하철역 실내 내비게이션 웹앱입니다.

사용자가 복잡한 지하철역 내부에서 현재 위치를 확인하고, 역 내부 시설 또는 역 주변 목적지와 가까운 출구까지 이동할 수 있도록 안내합니다. 자동 안내만으로 해결하기 어려운 상황에서는 WebRTC 기반 상담을 통해 역무원 또는 상담자가 사용자의 화면과 위치 정보를 보며 도움을 줄 수 있습니다.

## 프로젝트 목표

기존 지도 서비스는 역 밖 길찾기에는 강하지만, 지하철역 내부의 층, 통로, 개찰구, 승강장, 출구까지의 실제 이동 경로를 세밀하게 안내하는 데 한계가 있습니다. 이 프로젝트는 외국인 관광객이 겪는 다음 문제를 해결하는 것을 목표로 합니다.

- 실내에서 GPS가 부정확해 현재 위치를 알기 어려운 문제
- 출구 번호를 모르거나 역 주변 장소와 연결되는 출구를 찾기 어려운 문제
- 한국어 안내판, 복잡한 환승 동선, 개찰구 안팎 구분 때문에 이동 방향을 판단하기 어려운 문제
- 큰 짐, 휠체어, 유모차 사용자가 계단 없는 경로를 찾기 어려운 문제
- 자동 안내가 실패했을 때 현장 도움을 즉시 받기 어려운 문제

## 핵심 사용자

| 사용자 | 설명 |
| --- | --- |
| 관광객 사용자 | 로그인 없이 웹앱에 접속해 현재 위치 확인, 목적지 검색, 출구 추천, 실내 경로 안내, 외부 지도 연계를 이용합니다. |
| 상담자·역무원 | 로그인 후 담당 역의 상담 요청을 확인하고, WebRTC 영상·음성 상담과 화면 동기화 기능으로 사용자를 지원합니다. |
| 관리자 | 역, 층별 지도, 시설, 경로 노드·간선, 주변 장소, 추천 출구, 상담자 계정을 관리합니다. |
| 동행 사용자 | 공유된 위치를 확인하고 해당 위치까지 실내 경로 안내를 받을 수 있습니다. 위치 공유는 MVP 도전 기능입니다. |

## MVP 범위

MVP는 서울 전체 지하철역이 아니라 1개의 대표 역사를 대상으로 핵심 사용자 흐름을 검증합니다. 대상 역 후보는 역삼역, 강남역, 선릉역, 신논현역이며, 최종 대상 역과 실제 시연 동선은 추후 확정합니다.

주요 흐름은 다음과 같습니다.

```text
웹앱 접속
→ 언어 선택
→ 권한 요청
→ 현재 역 확인
→ 현재 위치 인식
→ 목적지 검색
→ 출구 추천
→ 실내 경로 안내
→ 출구 도착 확인
→ 네이버지도 연계
→ 문제 발생 시 WebRTC 상담
```

MVP 필수 기능은 다음과 같습니다.

- 한국어·영어 언어 선택
- 위치, 카메라, 마이크 권한 요청 및 제한 모드 제공
- GPS 기반 주변 역 후보 조회와 직접 역 선택
- 카메라 기반 VPS 또는 보조 인식을 통한 현재 위치 확인
- VPS 실패 시 재촬영, 랜드마크 선택, 지도 수동 선택, 상담 요청 제공
- 층별 2D 실내 지도와 좌표 오버레이
- 역 내부 시설 및 역 주변 장소 검색
- 역 주변 장소와 가까운 출구 자동 추천
- 빠른 경로, 계단 없는 경로, 엘리베이터 중심 경로 탐색
- 카메라 화면과 지도 화면을 결합한 경로 안내
- 출구 도착 후 네이버지도 길찾기 연계
- 상담자 로그인, 상담 요청 목록, WebRTC 상담
- 역, 지도, 시설, 경로, 상담자 기본 관리자 기능

## 주요 기능

### 실내 위치 인식

스마트폰 카메라로 역 내부를 비추면 VPS 또는 보조 인식 방식으로 현재 역, 층, 위치, 바라보는 방향, 신뢰도를 확인합니다. 자체 VPS는 스마트폰 촬영 영상에서 프레임 이미지를 추출하고 COLMAP 기반 3D Map 구축을 시도합니다.

VPS가 불안정할 경우 다음 순서로 대체 흐름을 제공합니다.

1. 지도에서 현재 위치 수동 선택
2. 주변 랜드마크 선택
3. QR/마커 기반 보조 인식
4. WebRTC 상담 연결

### 실내 지도와 경로 탐색

대상 역의 층별 지도 이미지를 사용하고, 지도 위에 현재 위치, 목적지, 시설, 출구, 경로를 좌표 기반으로 표시합니다. 경로 데이터는 노드와 간선으로 관리하며, 백엔드에서 Dijkstra 알고리즘을 우선 사용합니다.

지원하는 경로 옵션은 다음과 같습니다.

| 화면 표시 | 내부 routeType | 기준 |
| --- | --- | --- |
| 빠른 경로 | `fastest` | 모든 활성 간선을 사용해 가장 빠른 경로를 찾습니다. |
| 계단 없는 경로 | `no_stairs` | 계단 간선을 제외합니다. |
| 엘리베이터 중심 경로 | `no_stairs_no_escalators` | 계단과 에스컬레이터 간선을 제외하고 평지와 엘리베이터 중심으로 안내합니다. |

### 목적지 검색과 출구 추천

사용자는 출구 번호를 몰라도 호텔, 음식점, 관광지, 쇼핑몰, 공연장, 랜드마크 같은 역 주변 장소를 검색할 수 있습니다. 서비스는 해당 장소와 연결된 추천 출구를 실내 목적지로 설정하고, 현재 위치에서 해당 출구까지 길을 안내합니다.

출구에 도착하면 사용자의 실제 GPS 위치를 출발지로 사용해 네이버지도 길찾기를 이어갑니다. 앱 링크가 실패하면 웹 링크를 제공하고, 웹 링크도 실패할 경우 장소명 또는 주소 복사 흐름을 제공합니다.

### WebRTC 상담

사용자는 주요 화면에서 상담을 요청할 수 있습니다. 상담 요청에는 현재 역, 현재 위치, 목적지, 문제 유형이 포함됩니다.

상담자는 전용 페이지에서 담당 역의 상담 요청을 확인하고 수락합니다. 상담 중에는 WebRTC 영상 또는 음성 연결을 사용하며, DataChannel을 통해 다음 이벤트를 사용자 화면에 반영합니다.

- `draw_arrow`: 사용자 화면에 방향 화살표 표시
- `set_destination`: 목적지 지정 또는 변경
- `update_location`: 사용자 현재 위치 보정
- `send_message`: 짧은 안내 메시지 표시
- `sync_status`: 상담 상태 동기화

## 인증과 세션

- 일반 관광객 사용자는 로그인하지 않고 `userSessionId` 기반 임시 세션으로 이용합니다.
- 사용자 세션은 마지막 활동 기준 24시간 만료를 기준으로 합니다.
- 상담자와 관리자는 JWT Access Token 기반으로 로그인합니다.
- JWT Access Token 만료 시간은 12시간입니다.
- Refresh Token은 MVP에서 생략합니다.
- 상담 세션 ID는 UUID 또는 ULID 기반 문자열을 사용합니다.

## 데이터 설계

주요 데이터 영역은 다음과 같습니다.

- 역, 층, 층별 지도 이미지
- 출구, 개찰구, 승강장, 화장실, 엘리베이터 등 시설
- 경로 탐색용 노드와 간선
- 역 주변 장소와 추천 출구 연결
- 비로그인 사용자 임시 세션
- 상담 요청, 상담 세션, 상담 이벤트
- 상담자와 관리자 계정
- VPS 맵, 기준 이미지, 위치 인식 로그
- 다국어 문구와 시설명 확장을 위한 번역 데이터

MVP에서는 다국어 데이터를 간소화해 주요 응답에 `nameKo`, `nameEn`을 함께 내려주고, 프론트엔드에서 선택 언어에 맞게 표시합니다.

## API 범위

MVP 필수 API는 다음 영역으로 나뉩니다.

- 사용자 세션: `POST /user-sessions`
- 역: `GET /stations/nearby`, `GET /stations/search`, `GET /stations/{stationId}`
- 지도/시설: `GET /stations/{stationId}/maps`, `GET /stations/{stationId}/facilities`
- 목적지/장소: `GET /destinations/search`, `GET /stations/{stationId}/places`, `GET /places/{placeId}/recommended-exits`
- 위치 인식: `POST /vps/localize`, `POST /localization/manual`
- 경로: `POST /routes/indoor/options`, `POST /routes/indoor`, `POST /routes/indoor/recalculate`
- 외부 지도: `POST /external-maps/directions`
- 상담: `POST /consultations`, `GET /consultations/{consultationId}`, `DELETE /consultations/{consultationId}`
- 상담자: `POST /counselors/login`, `GET /counselor/consultations`, `POST /consultations/{consultationId}/accept`
- WebRTC signaling: `WS /ws/signaling`
- 관리자: 역, 층, 지도, 시설, 경로, 주변 장소, 상담자 계정 관리 API

## 비기능 기준

- 모바일 웹앱은 Android Chrome 기준으로 안정성을 확보하고, iOS Safari는 주요 화면 접근과 기본 흐름을 확인합니다.
- 일반 모바일 네트워크에서 첫 화면은 3초 이내, 시연 환경에서는 2초 이내 표시를 목표로 합니다.
- 위치 인식 결과는 5초 이내 반환을 목표로 하며, 8초 이상 지연되면 대체 흐름을 제공합니다.
- 경로 탐색 결과는 2초 이내 반환을 목표로 합니다.
- HTTPS 환경에서 위치정보, 카메라, 마이크, WebRTC 기능을 사용합니다.
- 일반 사용자, 상담자, 관리자 권한을 분리합니다.
- 카메라 이미지는 위치 인식 처리 후 즉시 폐기하고, 상담 영상은 저장하지 않는 것을 기본 원칙으로 합니다.
- 네트워크, VPS, WebRTC, 외부 지도 연계 실패 시 대체 흐름을 제공합니다.
