카메라 화각 진단

촬영 화면이 광각으로 보이는 원인이 렌즈인지 화면 크롭인지 가른다. adb 없이 폰 브라우저만으로 확인한다. HTTPS 로 접속해야 카메라가 열린다.

1. 수정 전 / 수정 후 비교

수정 후는 cameraStream.ts 의 렌즈 선택과 같은 규칙이다 — 라벨에서 camera N, facing back 을 읽어 N 이 가장 작은 것을 연다. 수정 전은 { facingMode: { ideal: 'environment' } } 만 준다. 이쪽이 광각으로 나오면 버그가 재현된 것이다. 상담 쪽(consultMedia.ts)은 { video: true } 로 연다.

2. 원본 비율 그대로 (크롭 없음)

이 화면이 이미 광각으로 보이면 렌즈 문제다. 여기서 정상인데 아래 상자에서만 넓어 보이면 CSS 크롭 문제다.

↑ 앱 촬영 화면과 같은 조건(object-fit: cover).

3. 지금 열린 트랙

아직 열지 않았다.

4. 장치 목록

권한을 허용하면 이름이 보인다.

렌즈가 여러 개면 여기서 하나씩 열어 본다. 초광각은 보통 화각이 눈에 띄게 넓다.

5. 장치 재구성 검증

앱 제약으로 연 뒤, 상담 화면과 같은 { video: true } 를 겹쳐서 연다. 안드로이드 크롬은 같은 카메라를 한 세션으로 공유해서, 두 번째 요청이 장치를 다시 구성하면 먼저 열린 트랙의 해상도까지 바뀐다. 그 현상이 실제로 일어나는지 본다.
